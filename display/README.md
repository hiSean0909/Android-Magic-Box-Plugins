# Display

Display is an offline Magic Box function that shows a scrolling text message.

Enter text and select its size, text color, background color, and italic style. Show the message in fullscreen, scrolling horizontally in a continuous loop. Return to the settings to edit it.

Import [display-v1.1-release.zip](release/display-v1.1-release.zip) into Magic Box. This plugin follows plugin standard 1.0 and requires host API 2 for fullscreen.
