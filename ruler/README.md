# Ruler

An offline ruler function for Magic Box. Import the ZIP package in `deliverables` using Magic Box and calibrate it against a physical ruler.

The ruler displays centimeters and millimeters on the left and inches and subdivisions on the right, with a shared zero point. It initially uses the device-reported screen measurements. Adjust the calibration slider against a physical ruler; the setting is saved for later use. Verify physical accuracy on the target device.
