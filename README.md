# Plugins

Magic Box plugins are independent offline extensions that can be imported into the host application.

| Function | Category | Description |
| --- | --- | --- |
| [2048](2048/README.md) | Game | Sliding tile game |
| [Ruler](ruler/README.md) | Tool | Calibrated screen ruler |
| [Display](display/README.md) | Tool | Fullscreen scrolling message |
| [Minesweeper](minesweeper/README.md) | Game | Mine-finding game |
| [Flappy Bird](flappy-bird/README.md) | Game | Obstacle navigation game |
