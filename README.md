# Plugins

## Introduction

This repository provides plugins for [Android Magic Box](https://github.com/hiSean0909/Android-Magic-Box) (latest commit: [cc6ab07](https://github.com/hiSean0909/Android-Magic-Box/commit/cc6ab0717789f3b450b7c6f874561cd7419a33f0)).

## Plugin Overview

Magic Box plugins are independent offline extensions that can be imported into the host application. Download a plugin ZIP and select **Plugins > Import > Import plugin from local** in Magic Box.

| Function | Category | Description |
| --- | --- | --- |
| [2048](2048/README.md) | Game | Built into Magic Box |
| [Ruler](ruler/README.md) | Tool | [Download](ruler/release/ruler-v1.0-release.zip) calibrated screen ruler |
| [Display](display/README.md) | Tool | [Download](display/release/display-v1.0-release.zip) fullscreen scrolling message |
| [Minesweeper](minesweeper/README.md) | Game | Built into Magic Box |
| [Flappy Bird](flappy-bird/README.md) | Game | Built into Magic Box |

## How to Use a Plugin

1. Install Magic Box on an Android 10 or later device.
2. Download a plugin ZIP from this repository and copy it to the device.
3. In Magic Box, select **Plugins > Import > Import plugin from local** and choose the ZIP file.
4. Find the plugin under **Plugins** or **Search**, then tap it to open it.
5. Use the plugin card's settings button to enable, disable, uninstall, export, or view information about the plugin.

Built-in plugins are installed automatically when Magic Box first opens. To update an imported plugin, import a ZIP with the same plugin ID.
